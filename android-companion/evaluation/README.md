The APK and source archive are the exact files previously prepared for version 0.5.0. The original ZIP excludes signing keys and local machine configuration. This directory is in the contributor's review branch, not the upstream project's default branch.

The recorded automated checks passed, but real-device installation, site downloads, airplane-mode reopening, notifications and the Android document picker still require verification. See the review notes before evaluating adoption.
